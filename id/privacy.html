Privasi

Diperbarui: 5 November 2026. NurVakti dioperasikan oleh Mehmet Kaan Ulu. Dukungan dan permintaan data: support.NurVakti@gmail.com.

Informasi di perangkat Anda

Anda tidak perlu memiliki akun. Catatan ibadah, catatan pribadi, favorit dan preferensi membaca secara bawaan tetap berada di perangkat Anda; semuanya tidak dikirim ke sistem iklan atau ke RevenueCat. Anda dapat mengekspor dan menghapusnya dari layar Privasi. Catatan tetap berada di perangkat sampai Anda menghapusnya atau menghapus data aplikasi; cadangan sistem operasi mengikuti pengaturan Anda sendiri.

Pilihan privasi Anda

Pengukuran, catatan pemasangan, dan pengumuman pemasaran bersifat opsional dan tidak dimulai tanpa izin Anda. Meski tanpa izin Anda, jenis perangkat (iOS/Android), versi aplikasi dan build, nomor NV acak, serta tanggal terakhir terlihat dikirim ke server kami untuk pembaruan, kompatibilitas, dukungan, dan keamanan. Catatan minimal ini tidak berisi durasi penggunaan, lokasi, akun, atau data kampanye, dan dihapus setelah 90 hari tidak digunakan. Jika notifikasi diizinkan di ponsel Anda, alamat notifikasi Anda disimpan, meski tanpa izin ini, hanya untuk pemberitahuan pembaruan, keamanan, dan layanan penting; mematikan izin notifikasi menghapusnya. Notifikasi pemasaran hanya dikirim dengan izin Anda. Waktu salat, Al-Qur’an dan pengingat pilihan tetap berfungsi jika ditolak. Iklan dan pembelian tidak bergantung pada pilihan ini. Ubah pilihan kapan saja di Pengaturan → Privasi.

Layar ini tidak memberikan izin lokasi atau notifikasi sistem. Pemilihan kota secara manual tetap tersedia. Pilihan kota, bahasa, dan tema Anda tidak terpengaruh.

Notifikasi dikirim melalui layanan Apple atau Google. Pencabutan izin segera menghentikan pemrosesan opsional di perangkat; pembersihan catatan server terkait dicoba lagi saat terhubung. Catatan pembelian yang diperlukan dan konten Anda tidak dihapus.

Persetujuan dan penolakan diingat. Pembukaan biasa tidak meminta keputusan lagi untuk akun dan tujuan yang sama. Perubahan akun atau tujuan dapat memerlukan keputusan baru. Pengumpulan opsional dan pengiriman antrean tidak dimulai tanpa izin terkait.

Agar kami bisa melihat masalah, hasil izin lokasi dan notifikasi, langkah penyiapan yang dicapai, dan munculnya layar galat juga dikirim sebagai kategori. Koordinat dan nama kota tidak dikirim.

Nomor dukungan

Aplikasi membuat nomor NV acak. Meskipun Anda menolak pengukuran, nomor ini disimpan di RevenueCat bersama akun aplikasi acak Anda agar kami dapat menemukan permintaan dukungan Anda. Isinya hanya nomor ini, tanpa informasi penggunaan, lokasi atau ibadah. Anda dapat meminta penghapusannya melalui alamat dukungan.

Lokasi dan layanan eksternal

Lokasi diambil hanya dengan izin Anda dan hanya selama tindakan yang memerlukannya; Anda dapat memakai kota manual, dan lokasi latar belakang tidak dikumpulkan. Waktu salat dihitung di perangkat Anda.

Zona waktu: Saat Anda menggunakan lokasi saat ini, koordinat Anda dikirim melalui HTTPS ke server kami sendiri untuk menemukan zona waktu. Server hanya menentukan zona waktu dan memberikan jawaban; server tidak menulis koordinat ke basis data. Jika server tidak dapat dijangkau, zona waktu diperkirakan di perangkat Anda.

Rute: Saat rute ke masjid dihitung, lokasi Anda saat ini dan lokasi masjid dikirim ke server kami sendiri, lalu dari sana ke penyedia rute openrouteservice (HeiGIT). Hasilnya disimpan di memori sementara server selama 5 menit agar rute yang sama dapat digunakan kembali; hasil itu tidak ditulis ke basis data.

Masjid terdekat: Titik pencarian dikirim ke server kami sendiri, yang membulatkannya hingga sekitar 100 meter dan menanyakan data OpenStreetMap (Overpass). Jika server tidak dapat dijangkau, titik pencarian dikirim langsung ke server Overpass.

Saat Anda membuka petunjuk arah eksternal, layanan peta yang Anda pilih menerima informasi ini. Server kami, infrastruktur hosting kami, dan penyedia layanan dengar/unduh audio dapat melihat detail koneksi seperti alamat IP Anda dalam permintaan jaringan; server kami menggunakannya untuk membatasi penyalahgunaan.

Aktivitas Langsung (iPhone)

Saat Anda sendiri memulai Aktivitas Langsung di iPhone, token sesi yang diterbitkan Apple dan isi aktivitas tersebut dikirim ke server kami sendiri agar layar dapat diperbarui ketika waktu salat berganti. Isinya terdiri dari nama dan waktu salat, zona waktu, label sumber waktu salat, preferensi tema dan tampilan, bahasa dan teks layar, serta, jika ditampilkan, nama masjid terdekat dan waktu berjalan kaki; isinya tidak memuat koordinat. Pembaruan sampai ke perangkat Anda melalui Apple Push Notification service (APNs). Satu sesi berlangsung paling lama 8 jam. Saat sesi berakhir atau Anda menghentikannya, token dan isi dihapus; hanya ringkasan token satu arah yang mencegah sesi dibuka kembali yang disimpan selama 8 jam lagi. Notifikasi langsung di Android berjalan di perangkat dan tidak menggunakan layanan ini.

Pembaruan aplikasi

Saat terhubung ke Wi-Fi, aplikasi memeriksa server kami sendiri untuk pembaruan yang tidak memerlukan versi toko baru. Permintaan ini mengirim platform, versi runtime aplikasi, kanal pembaruan, ID pembaruan yang terpasang, dan ID pembaruan acak yang unik untuk pemasangan Anda (EAS-Client-ID). ID ini digunakan untuk meluncurkan pembaruan secara bertahap dan memilih perangkat uji; ID ini tidak bergantung pada pilihan pengukuran Anda. Nama, lokasi dan isi ibadah Anda tidak dikirim. ID ini biasanya tidak dicatat; hanya selama periode pencatatan uji yang terbatas, ID, platform, versi runtime dan waktu permintaan ditulis ke sebuah berkas di server.

Laporan masalah dan saran

Saat Anda mengirim formulir laporan masalah atau saran masjid di aplikasi, kategori atau jenis saran, ID catatan atau masjid, deskripsi Anda dan tautan sumber jika ada dikirim ke server kami sendiri. Aplikasi tidak menambahkan akun, lokasi atau ID perangkat ke kiriman ini. Kiriman disimpan sebagai catatan yang tidak dapat diubah untuk peninjauan dan audit, tanpa jangka waktu penghapusan otomatis. Karena itu, jangan menulis nama, lokasi persis, kunci akses, detail kartu atau riwayat ibadah pribadi Anda dalam formulir ini.

Jika Anda mengirim email kepada kami, alamat dan pesan Anda digunakan untuk membalas dan diproses oleh layanan email Google.

Iklan

Semua orang yang tidak memiliki NurVakti Pro melihat iklan non-personalisasi. Iklan adalah bagian dari versi gratis; tidak ada izin iklan tersendiri, dan iklan tidak bergantung pada pilihan pengukuran Anda. Izin Apple ATT tidak diminta, sehingga ID iklan iPhone (IDFA) tidak tersedia bagi SDK iklan.

Penyedia iklan adalah Google AdMob dan Unity LevelPlay / ironSource / Unity Ads / Yandex Ads. Aplikasi tidak mengirim lokasi akurat, catatan ayat atau riwayat ibadah ke sistem iklan. SDK ini dapat memproses alamat IP (perkiraan wilayah), pengenal perangkat, interaksi iklan dan informasi diagnostik/kinerja untuk menampilkan dan mengukur iklan. Iklan non-personalisasi tidak berarti tidak ada data yang diproses.

Di wilayah yang diwajibkan oleh Google, Google menampilkan formulir pilihannya sendiri (Google UMP); formulir ini hanya memengaruhi iklan Google. Pro tersedia untuk penggunaan bebas iklan; pengguna Pro yang terverifikasi tidak melihat iklan.

Pengukuran kinerja opsional

Pengukuran dinonaktifkan secara bawaan dan hanya dimulai dengan persetujuan tegas. NurVakti memakai ID acak untuk analisis dan pemecahan masalah; jika Anda mengikuti undangan, ID ini dapat dikaitkan dengan akun pembelian terverifikasi. Layanan undangan kami dan RevenueCat memproses hubungan pengundang, pembelian, pembatalan, pengembalian dana dan hak Pro untuk menjalankan hadiah serta mencegah penyalahgunaan. Pengundang tidak melihat nama atau rincian pembayaran. Catatan hak dan keamanan disimpan sesuai kebutuhan; hash akses yang dicabut disimpan agar tidak digunakan kembali. Permintaan data: support.NurVakti@gmail.com.

Hanya durasi aplikasi di latar depan dan peristiwa notifikasi dijadwalkan, diterima, dibuka atau gagal yang dikirim. Konten, riwayat ibadah dan lokasi tidak dikirim. Akun tidak diperlukan. Platform perangkat (iOS/Android), versi aplikasi dan build, serta kunjungan pertama dan terakhir di latar depan juga dikirim.

Peristiwa disimpan selama 30 hari. Menonaktifkan menghentikan pengumpulan dan meminta penghapusan; permintaan luring akan dicoba lagi. Masa ini hanya berlaku untuk peristiwa pengukuran; catatan pemasangan dan notifikasi memiliki masa simpan tersendiri.

Penjadwalan bukan bukti pengiriman. Tidak semua pengiriman di latar belakang dapat diukur. Penggunaan sebelumnya dan catatan yang belum terkirim tidak ditambahkan ke laporan.

Catatan pemasangan dan aktivitas

Bantu tingkatkan NurVakti dengan mengirim jenis perangkat, versi, kunjungan, waktu penggunaan dan diagnostik notifikasi ke server kami melalui ID acak. Platform, versi aplikasi, dan waktu terakhir dibuka dikirim ke layanan kami, tanpa nama, lokasi, atau isi ibadah Anda. Jika Anda datang melalui tautan iklan, hanya label sumber dan kampanye dalam tautan itu yang dicatat; ID iklan (IDFA/AAID) tidak digunakan dan tidak ada pelacakan lintas aplikasi. Catatan disimpan sampai Anda menonaktifkan izin ini atau menghapus data Anda. Menonaktifkannya menghentikan pengukuran dan menghapus catatan ini, sehingga hanya catatan teknis minimal yang tersisa; penghapusan selesai saat terhubung. Jika Anda memiliki akun pembelian RevenueCat, catatan ini dapat ditautkan ke akun tersebut. Tujuan penggunaan yang Anda pilih saat pertama membuka aplikasi (mis. Al-Qur’an, zikir) juga dikirim dengan izin ini. Semua fitur NurVakti tetap berfungsi tanpa izin ini.

Undang dan dapatkan hadiah

Bergabung membuat identitas pembelian pribadi di perangkat ini. Kode undanganmu bersifat publik; kunci pemulihanmu rahasia.

Setiap teman harus mempertahankan pembelian berbayar pertamanya selama 30 hari tanpa pembatalan atau pengembalian dana. Berlaku untuk paket bulanan, tahunan, dan seumur hidup. Jika kontribusi yang sah kurang dari lima, hadiah sementara dicabut. Setelah lima kontribusi melewati 30 hari, hadiah menjadi permanen.

Uji coba, penawaran gratis, pembelian uji, dan berbagi keluarga tidak dihitung. Hak pengembalian dana toko tidak berubah. Keikutsertaan opsional; aplikasi gratis tetap tersedia.

Kunci pemulihan memberi akses penuh ke identitas undanganmu. Simpan di pengelola kata sandi pribadi. Jangan kirim kepada teman, administrator, atau dukungan.

Pengumuman NurVakti

Notifikasi opsional tentang fitur baru dan kabar aplikasi. Alamat notifikasi, bahasa, zona waktu, serta preferensi suara dan jam tenang disimpan dengan aman dan dihapus setelah 90 hari tanpa pembaruan. Saat dinonaktifkan, notifikasi pemasaran tidak dikirim; jika notifikasi diizinkan di ponsel, pendaftaran yang sama tetap ada hanya untuk pemberitahuan layanan. Pengingat salat tetap terpisah.

Penyimpanan dan permintaan

Penyimpanan catatan yang dipegang penyedia, beserta kewajiban keamanan dan hukum, tunduk pada kebijakan masing-masing penyedia; menghapus data di perangkat Anda tidak otomatis menghapus catatan tersebut. Anda dapat mengirim permintaan akses, perbaikan atau penghapusan ke alamat dukungan. Jangan mengirim catatan lokasi atau ibadah yang tidak perlu. Penyedia layanan dapat memproses data pada sistem di luar negara Anda.

Masa simpan di server kami: peristiwa pengukuran dan catatan kunjungan 30 hari; catatan pemasangan berizin sampai Anda menonaktifkan izin atau menghapus data; catatan teknis minimal 90 hari setelah penggunaan terakhir; pendaftaran notifikasi dihapus jika tidak diperbarui selama 90 hari.

Menghapus data di aplikasi juga menghapus catatan ini; jika Anda membuka aplikasi lagi, catatan minimal baru dibuat. Untuk penghapusan dan permintaan lain: support.nurvakti@gmail.com.

Situs web ini

Situs ini tidak menggunakan cookie, analitik, iklan atau formulir. Bahasa yang Anda pilih hanya disimpan di browser Anda; saat bahasa dipilih secara otomatis, hanya pengaturan bahasa browser Anda yang dibaca dan lokasi Anda tidak diambil. Tautan berbagi dapat memuat referensi ayat, ID OSM publik atau kode undangan publik; tautan itu tidak memuat kunci pemulihan rahasia. GitHub Pages dapat memproses informasi akses teknis.
